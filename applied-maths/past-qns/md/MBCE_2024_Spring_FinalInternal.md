#### 1.
a) Define a harmonic function. Is the function $v = x^3 - 3xy^2$ harmonic? If yes, find a corresponding harmonic conjugate and the analytic function $f(z) = u + i v$. **[8]**

b) State the Cauchy Integral Formula for derivatives. Evaluate:
$$\oint_C \frac{z+1}{z^3 - 2z^2} \, dz$$
where $C$ is the unit circle $|z| = 1$, counter-clockwise. **[7]**

---

#### 2.
a) Find the Laurent series for $f(z) = \frac{1}{(z-1)(z-2)}$ in the regions:
1. $0 < |z| < 1$
2. $1 < |z| < 2$
3. $|z| > 2$
**[7]**

b) Define singularity, zeros, and poles of a function. Evaluate:
$$\oint_C \frac{e^z}{(z+1)^3} \, dz$$
where $C$ is the ellipse $4x^2 + 9y^2 = 16$. **[8]**

---

#### 3.
a) Define Fourier integral. By choosing a suitable function, show that:
$$\int_0^\infty \frac{\cos xw + w \sin xw}{1 + w^2} \, dw = \begin{cases} 
0, & \text{if } x < 0 \\ 
\frac{\pi}{2}, & \text{if } x = 0 \\ 
\pi e^{-x}, & \text{if } x > 0 
\end{cases}$$
**[8]**

b) Find the Fourier transform of the function $f(x) = e^{-|x|}$. **[7]**

---

#### 4.
a) State and prove the first shifting theorem of Z-transform. Evaluate the Z-transform of $a^n \cos(bn)$ and $a^n \sin(bn)$. **[8]**

b) Solve the difference equation by using Z-transform:
$$y_{n+2} - 4y_{n+1} + 4y_n = 2^n$$
with $y_0 = 0$, $y_1 = 1$. **[7]**

---

#### 5.
a) What do you mean by analyticity of a function $f(z)$? State the Cauchy-Riemann equations and hence show that they are the necessary conditions for the function to be analytic. **[8]**

b) State Cauchy's Residue Theorem. By applying Cauchy's Residue Theorem, evaluate:
$$\oint_C \frac{e^z}{z^2 + 4} \, dz$$
where $C: |z| = 3$. **[7]**

---

#### 6. Solve the following: **[4 x 5 = 20]**
a) Prove $Z(a^n) = \frac{z}{z-a}$.
b) Check the analyticity of $f(z) = \bar{z}$.
c) Find the Z-transform of $\sin(n\theta)$ and $\cos(n\theta)$.
d) Show that $f(z) = z \bar{z}$ is not analytic.
e) Find the Fourier sine transform of:
$$f(x) = \begin{cases} 
x, & 0 < x < 1 \\ 
0, & x > 1 
\end{cases}$$
f) State and prove the Initial Value Theorem of Z-transform. Find the inverse Z-transform of $F(z) = \frac{z^2+z}{z^2-2z+2}$.
