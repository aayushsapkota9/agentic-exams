### Attempt all the questions.

#### 1. 
a) Define analyticity of a function $f(z)$. Show that the necessary condition for the function $f(z) = u(x,y) + i v(x,y)$ to be analytic on a domain $D$ is $u_x = v_y$ and $u_y = -v_x$ at each point $(x,y)$ of $D$. **[8]**

b) State and prove Cauchy Integral Formula. Evaluate the integral:
$$\oint_C \frac{e^{2z}}{z^2 - 1} \, dz$$
where $C: |z| = 2$. **[7]**

**OR**

State Cauchy's Residue Theorem and using it, evaluate:
$$\oint_C \frac{z^2}{(z^2+1)(z-1)^3(z+3)} \, dz$$
where $C: |z| = 2$ counter-clockwise. **[7]**

#### 2.
a) Find the Laurent series expansion for $f(z) = \frac{7z-2}{(z+1)(z-3)}$ in the regions:
1. $0 < |z+1| < 1$
2. $1 < |z+1| < 3$
**[8]**

b) Define bilinear transformation. Find the bilinear transformation which maps the points $z = 0, -1, i$ onto the points $w = i, 0, \infty$. Also, find the image of the unit circle $|z| = 1$. **[7]**

#### 3.
a) State and prove the first shifting theorem on Z-transform. Find the Z-transform of $e^{-at}$ and then find $Z\left(\cos \frac{\theta}{2}\right)$ and $Z\left(\sin \frac{\theta}{2}\right)$. **[8]**

b) Solve the difference equation:
$$y_{n+2} - 7y_{n+1} + 12y_n = 2^n$$
with $y_0 = 0, y_1 = 0$ by using Z-transform. **[7]**

c) Show that $Z[n f(t)] = -z \frac{d}{dz} [F(z)]$, where $F(z) = Z[f(t)]$. **[7]**

#### 4.
a) Find the solution of the one-dimensional wave equation:
$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$$
with initial velocity $g(x)$, initial deflection $f(x)$, and boundary conditions $u(0, t) = 0 = u(L, t)$. **[7]**

b) Express the Laplacian $\nabla^2 u = u_{xx} + u_{yy}$ in polar coordinates. **[8]**

#### 5.
a) Derive the two-dimensional heat equation completely with necessary assumptions. **[7]**

**[8]**

#### 6.

**[7]**

\pi e^{-x}, & \text{if } x > 0 
\end{cases}$$
