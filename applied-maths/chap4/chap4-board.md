## 2025 Fall
**Pokhara University | Semester: Fall | Year: 2025**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q4.
a) Find the Fourier cosine transform of $f(x) = e^{-mx}$ for $m > 0$. **[7]**

b) Solve the one-dimensional wave equation with initial deflection $f(x)$ and initial velocity zero. **[8]**

**OR**

Determine the solution of the one-dimensional heat equation:
$$\frac{\partial u}{\partial t} = c^2 \frac{\partial^2 u}{\partial x^2}$$
subject to the boundary conditions $u(0, t) = 0$, $u(L, t) = 0$ and initial temperature $u(x, 0) = f(x)$, where $L$ is the length of the bar. **[8]**

#### Q6 (Solve Any Two): **[2 × 5 = 10]**
b) Show that:
$$\int_0^\infty \frac{w \sin xw}{a^2 + w^2} \, dw = \frac{\pi}{2} e^{-ax}$$
where $x > 0, a > 0$.

## 2025 Spring
**Pokhara University | Semester: Spring | Year: 2025**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q4.
a) Using Fourier integral representation, show that:
$$\int_0^\infty \frac{\cos xw + w \sin xw}{1 + w^2} \, dw = \begin{cases} 0 & \text{if } x < 0 \\ \frac{\pi}{2} & \text{if } x = 0 \\ \pi e^{-x} & \text{if } x > 0 \end{cases}$$
**[7]**

b) Find the Fourier cosine transform of $f(x) = e^{-x}$ and by using Parseval's identity, show that:
$$\int_0^\infty \frac{dx}{(1+x^2)^2} = \frac{\pi}{4}$$
**[8]**

#### Q7 (Attempt all): **[4 × 2.5 = 10]**
a) Evaluate $\displaystyle\oint_C \frac{2z}{(z-1)(z+3)} \, dz$, where $C$ is the circle $|z| = 2$ counter-clockwise, using Cauchy's residue theorem.

b) Check whether the function $u(x, y) = z\bar{z}$ is analytic or not.

c) Find $Z(n^2)$.

d) Solve $u_x + u_y = 0$ by using separation of variables.

#### Q6.
a) Find the Fourier cosine transform of $f(x) = e^{-mx}$ for $m > 0$, and then show that:
$$\int_0^\infty \frac{\cos kx}{m^2 + x^2} \, dx = \frac{\pi}{2m} e^{-mk}$$
**[7]**

$$\int_0^\infty \frac{\cos xw + w \sin xw}{1 + w^2} \, dw = \begin{cases} 0, & \text{if } x < 0 \\ \frac{\pi}{2}, & \text{if } x = 0 \\ \pi e^{-x}, & \text{if } x > 0 \end{cases}$$
**[8]**

#### Q7 (Attempt all): **[4 × 2.5 = 10]**
a) Check the analyticity of $f(z) = \bar{z}$.

b) Find $Z(a^n)$.

c) Find the solution of the partial differential equation $u_{xx} + 9u = 0$.

d) Define linear partial differential equation with a suitable example.

## 2024 Fall
**Pokhara University | Semester: Fall | Year: 2024**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q6.
a) Find the Fourier cosine transform of $f(x) = e^{-mx}$ for $m > 0$, and then show that:
$$\int_0^\infty \frac{\cos kx}{1 + x^2} \, dx = \frac{\pi}{2} e^{-k}$$
**[7]**

**OR**

Find the Fourier transform of $f(x) = xe^{-x^2}$.

b) Show that:
$$\int_0^\infty \frac{\cos wx + w \sin wx}{1 + w^2} \, dw = \begin{cases} 0, & \text{if } x < 0 \\ \frac{\pi}{2}, & \text{if } x = 0 \\ \pi e^{-x}, & \text{if } x > 0 \end{cases}$$
**[8]**

#### Q7 (Attempt any two): **[2 × 5 = 10]**
a) Find Laurent series of the function $f(z) = \frac{z+3}{z(z+1)(z-2)}$ in the region $1 < |z| < 2$.

b) Find the solution of the differential equation $y^2 u_x - x^2 u_y = 0$ by using separation of variables.

c) Show that $u(x, y) = e^{2x}(x \cos 2y - y \sin 2y)$ is a harmonic function. Find its harmonic conjugate.
