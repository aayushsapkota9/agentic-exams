## 2025 Fall
**Pokhara University | Semester: Fall | Year: 2025**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q1.
a) State and prove the necessary conditions (Cauchy-Riemann equations) for a complex function to be analytic. **[8]**

b) Prove that $u = y^3 - 3x^2y$ is a harmonic function. Determine its harmonic conjugate and find the corresponding analytic function $f(z) = u + i v$. **[7]**

c) State the Cauchy Integral Formula for derivatives. Evaluate:
$$\oint_C \frac{z+1}{z^3 - 2z^2} \, dz$$
where $C$ is the unit circle $|z| = 1$, counter-clockwise. **[5]**

#### Q2.
a) Find the series expansion of the function $f(z) = \frac{7z-2}{(z+1)(z-3)}$ in the regions:
1. $|z| < 1$
2. $1 < |z| < 3$

**[7]**

b) Define singularity, zeros, and poles of a function. Evaluate:
$$\oint_C \frac{e^z}{(z+1)^3} \, dz$$
where $C$ is the ellipse $4x^2 + 9y^2 = 16$. **[8]**

c) Define bilinear transformation. Find the bilinear transformation which maps the points $z = 0, -i, i$ onto $w = i, 0, \infty$. Also find the image of the unit circle $|z| = 1$. **[7]**

#### Q6 (Solve Any Two): **[2 × 5 = 10]**
a) Find the Z-transform of $a^n \cos(bn)$.

b) Show that $\displaystyle\int_0^\infty \frac{w \sin xw}{a^2 + w^2} \, dw = \frac{\pi}{2} e^{-ax}$ where $x > 0, a > 0$.

c) Solve $u_{xx} + u_{yy} = 0$ by using the method of separation of variables.

## 2025 Spring
**Pokhara University | Semester: Spring | Year: 2025**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q1.
a) Define analytic function. Show that the necessary condition for a function $f(z) = u + iv$ to be analytic is $u_x = v_y$ and $u_y = -v_x$. **[7]**

b) Define harmonic function. Check $u = \sin x \cosh y$ is harmonic or not? If yes, find a corresponding harmonic conjugate $v$ of $u$ and corresponding analytic function $f(z)$. **[8]**

#### Q2.
a) Find the Laurent's series expansion of $f(z) = \frac{4z+3}{z^3 - z^2 - 6z}$ in the following regions:
1. $0 < |z| < 2$
2. $2 < |z| < 3$
3. $|z| > 3$

**[7]**

**OR**

Define bilinear transformation. Find the bilinear transformation which maps the points $z = 0, -1, i$ onto the points $w = i, 0, \infty$. Also, find the image of unit circle $|z| = 1$.

b) State and prove Cauchy integral formula. Evaluate:
$$\oint_C \frac{e^{2z}}{(z-1)^4} \, dz$$
where $C$ is the circle $|z| = 2$ in counter-clockwise direction. **[8]**

#### Q7 (Attempt all): **[4 × 2.5 = 10]**
a) Evaluate $\displaystyle\oint_C \frac{2z}{(z-1)(z+3)} \, dz$, where $C$ is the circle $|z| = 2$ counter-clockwise, using Cauchy's residue theorem.

b) Check whether the function $u(x, y) = z\bar{z}$ is analytic or not.

c) Find $Z(n^2)$.

d) Solve $u_x + u_y = 0$ by using separation of variables.

## 2024 Spring
**Pokhara University | Semester: Spring | Year: 2024**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q1.
a) Define analyticity of a function $f(z)$. Show that the necessary condition for the function $f(z) = u(x,y) + i v(x,y)$ to be analytic on a domain $D$ is $u_x = v_y$ and $u_y = -v_x$ at each point $(x,y)$ of $D$. **[8]**

b) State and prove Cauchy Integral Formula. Evaluate the integral:
$$\oint_C \frac{e^{2z}}{z^2 - 1} \, dz$$
where $C: |z| = 2$. **[7]**

**OR**

State Cauchy's Residue Theorem and using it, evaluate:
$$\oint_C \frac{z^2}{(z^2+1)(z-1)^3(z+3)} \, dz$$
where $C: |z| = 2$ counter-clockwise. **[7]**

#### Q2.
a) Find the Laurent series expansion for $f(z) = \frac{7z-2}{(z+1)(z-3)}$ in the regions:
1. $0 < |z+1| < 1$
2. $1 < |z+1| < 3$

**[8]**

b) Define bilinear transformation. Find the bilinear transformation which maps the points $z = 0, -1, i$ onto the points $w = i, 0, \infty$. Also, find the image of the unit circle $|z| = 1$. **[7]**

#### Q7 (Attempt all): **[4 × 2.5 = 10]**
a) Check the analyticity of $f(z) = \bar{z}$.

b) Find $Z(a^n)$.

c) Find the solution of the partial differential equation $u_{xx} + 9u = 0$.

d) Define linear partial differential equation with a suitable example.

## 2024 Fall
**Pokhara University | Semester: Fall | Year: 2024**
*Full Marks: 100 | Pass Marks: 45 | Time: 3 hrs.*

#### Q1.
a) Define analyticity of a function $f(z)$. Show that the necessary condition for the function $f(z) = u(x, y) + iv(x, y)$ to be analytic on a domain $D$ is $u_x = v_y$ and $u_y = -v_x$ at each point $(x, y)$ of $D$. **[7]**

b) State and prove Cauchy integral formula. Evaluate the integral:
$$\oint_C \frac{e^{5z}}{(z+i)^4} \, dz$$
where $C: |z| = 2$. **[8]**

#### Q2.
a) State Cauchy Residue Theorem. By applying Cauchy Residue Theorem, evaluate:
$$\oint_C \frac{dz}{(z^2 + 4)^3}$$
where $C: |z - i| = 2$. **[8]**

b) Find the linear transformation that maps $z = 0, z = 1, z = \infty$ into the points $w = -3, w = -1, w = 1$ and find the fixed point of the transformation. **[7]**

#### Q7 (Attempt any two): **[2 × 5 = 10]**
a) Find Laurent series of the function $f(z) = \frac{z+3}{z(z+1)(z-2)}$ in the region $1 < |z| < 2$.

b) Find the solution of the differential equation $y^2 u_x - x^2 u_y = 0$ by using separation of variables.

c) Show that $u(x, y) = e^{2x}(x \cos 2y - y \sin 2y)$ is a harmonic function. Find its harmonic conjugate.
